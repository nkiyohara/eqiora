# Expected values

This case introduces no expected value or tolerance. The exact v1 graph and
symmetric v2 graph bytes, lengths, digests, observations, receipt, and lineage
membership/counts are inherited from the accepted predecessor cases listed in
[`../references/README.md`](../references/README.md). The exact planar section
is inherited separately and is derived only from the distinct DFG-sized graph
fixture. The new oracle freezes explicit-versus-compatibility equality for
each graph route and the required rejection boundary.
