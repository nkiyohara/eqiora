# Models

No durable Model fixture is authoritative for this case, and none is stored
here. A durable realization-to-source binding wire and cross-platform mesh-byte
identity are both nonclaims of this slice, so a fixture in this directory could
not carry the claim even if one existed.

The registered Rust evidence constructs the exact source in-process — the
DFG-shaped 2.2 m by 0.41 m rectangle with one radius-0.05 m circle centred at
[0.2, 0.2] m — and realizes the chordal mesh from that value directly, binding
it by digest rather than by a stored file. Every expected value the evidence
checks is frozen by [`../oracle.py`](../oracle.py) and indexed in
[`../case.toml`](../case.toml); nothing in this directory is an input to that
comparison.
