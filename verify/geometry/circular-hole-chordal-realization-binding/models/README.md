# Runtime witness construction

This relational case has no checked-in production artifact bytes. The focused
Rust evidence constructs one validated exact circular-hole source, its chordal
owner, canonical realized region, conforming affine-triangle mesh, and
Model-free authored-region correspondence through their public constructors.

It then captures and externally replays the durable binding. A second
cell-renumbered conforming mesh and its freshly derived correspondence prove
that a different conforming mesh is accepted only under its own mesh,
correspondence, and binding identities. Runtime binary64 resource digests and
observations are deliberately not copied into this directory as constants.
