# Independent oracle boundary

The expected bounds, extents, and volumes in `expected/oracle.json` were fixed
before implementation. One derivation substituted the Parameter analytically;
the other evaluated the six endpoint leaves directly and multiplied the three
independently obtained extents. Both routes agreed exactly on the two finite
decimal fixtures.

This reference does not validate a regeneration plan, mesh, CAD kernel,
topology change, source rewrite, multi-Domain dependency, or numerical solve.
