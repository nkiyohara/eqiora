# Model fixtures

No Model fixture is stored here, and none is authoritative for this package.
The frozen [`expected/boundary-scope-contract.json`](../expected/boundary-scope-contract.json)
is an artificial symbolic table — not an executable Model, not a canonical
geometry artifact, and it reproduces no canonical byte string, byte length or
content digest. Its handles `A`, `B` and `C` are opaque stand-ins that the
implementing lane binds to real canonical artifacts.
