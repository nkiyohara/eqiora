# External spatial Component binding

This case closes one definitions-only `.eqi` Component against one exact
client-supplied canonical Geometry and returns the existing immutable common
`ModelDocument`.

The source owns only typed volume and boundary support slots, a Parameter,
Field, and Relations. The client-neutral binding supplies the Geometry digest,
named region and boundary entity sets, the exact boundary-parent slot, and an
explicit coherent-SI scalar value. Compiler-owned root occurrence expansion
then enters the existing hierarchy blueprint and typed transaction lowerer.
No Cartesian domain, formatted source, compiled transaction rewrite, or second
lowerer is constructed.

The ordinary positive path authenticates entity-set dimensions against the
supplied `CanonicalGeometryV1`, crosses the existing transaction envelope and
atomic graph commit, admits semantic support with the exact Geometry closure,
and reconstructs the canonical current Model artifact. Negative paths reject
missing supports, duplicate roles or entity sets, foreign Geometry identity,
and region/boundary dimension mismatch before a partial Model is returned.
The ordinary Component binder continues to own missing, extra, duplicate,
non-finite, and dimension-invalid Parameter rejection.

This case reuses the registered Component-support, Model geometry-reference,
and geometry-backed semantic-admission contracts. It adds no persisted schema,
source geometry syntax, package resolver, Python API, Mesh, Realization, solve,
scientific expected value, tolerance, or result claim.
