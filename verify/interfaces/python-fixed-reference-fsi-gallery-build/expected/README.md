# Expected evidence

The gate requires a complete 450-frame PNG sequence, lossless poster, VP9 WebM,
H.264 MP4, two-panel reduced-motion PNG, descriptive text, and canonical private
record. Every output digest is recomputed. Video bytes must reproduce when the
same frames are re-encoded in the same recorded producer and encoder profile;
no cross-platform golden media bytes or pixel-level scientific oracle is
claimed.
