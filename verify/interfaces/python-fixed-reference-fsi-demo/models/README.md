# Input Model

The installed wheel carries a build-copied byte-exact copy of
`verify/fsi/fixed-reference-monolithic-step-2d/models/direct.eqi`. Python reads
and compiles that source through the ordinary current owner before invoking
`FixedMeshMonolithic` resolution and the common Run path. No historical codec
selector, second FSI Model fixture, or Python-authored coupling graph is
introduced.
