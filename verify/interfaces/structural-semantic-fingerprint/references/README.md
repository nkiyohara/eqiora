# References

The contract is specified by
[RFC 0073](../../../../rfcs/0073-structural-semantic-fingerprint.md). Exact
Model artifact identity remains governed by
[RFC 0008](../../../../rfcs/0008-canonical-artifact-wire-v1.md) and its
successor codecs; the version-neutral exact reference is governed by
[RFC 0037](../../../../rfcs/0037-version-neutral-model-artifact-reference.md).

The canonical-label procedure uses exact partition refinement followed by
bounded individualization/backtracking. It does not claim that one-dimensional
color refinement alone decides graph isomorphism.
