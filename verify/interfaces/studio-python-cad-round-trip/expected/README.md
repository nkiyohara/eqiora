# Expected evidence

The files under `models/` are the exact expected UTF-8 source bytes. They were
precommitted by the non-implementing oracle owner before the native renderer or
Studio interaction was implemented. Production tests consume them verbatim;
they must not be reformatted or regenerated by the implementation under test.

Graph bytes, digests, observations, face provenance, tolerances, and build
lineage are not owned here. They are compared through the public installed API
against the existing frozen native geometry authorities.
