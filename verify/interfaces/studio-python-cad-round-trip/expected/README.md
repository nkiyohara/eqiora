# Expected evidence

The Python files under
[`bindings/python/tests/fixtures/studio_python_cad_round_trip`](../../../../bindings/python/tests/fixtures/studio_python_cad_round_trip)
are the exact expected UTF-8 source bytes. They were
precommitted by the non-implementing oracle owner before the native renderer or
Studio interaction was implemented. Production tests consume them verbatim;
they must not be reformatted or regenerated by the implementation under test.
They are intentionally frozen in formatter-canonical layout. Formatting must be
idempotent; a formatter delta is an oracle change and requires risk-focused
review against independently derived expected bytes, never regeneration from
the implementation output.

`models/hostile.json` freezes the negative corpus. Its placeholder bases and
mutation recipes are part of the oracle: tests substitute the named accepted
v1/v2 graph or source, apply exactly the stated mutation, and require the stated
disposition.

Graph bytes, digests, observations, face provenance, tolerances, and build
lineage are not owned here. They are compared through the public installed API
against the existing frozen native geometry authorities.
