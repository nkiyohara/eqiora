# Expected evidence

There is no adapter-owned expected-value source. The Python assertions reuse
the exact canonical bytes, graph digests, analytic observations, face
provenance, tolerance receipt, and topology lineage already frozen by the two
native geometry cases. Any disagreement is a projection defect; this case does
not tune or replace those authorities.

The atomic topology-name route adds no expected numeric value: it must reproduce
those same accepted Geometry bytes and digest. Its evidence is structural and
falsifies foreign, incomplete, repeated, mixed-dimensional, and non-handle
mappings before any Python-owned interpretation.
