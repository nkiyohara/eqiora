# Expected evidence

There is no adapter-owned expected-value source. The Python assertions reuse
the exact canonical bytes, graph digests, analytic observations, face
provenance, tolerance receipt, and topology lineage already frozen by the two
native geometry cases. Any disagreement is a projection defect; this case does
not tune or replace those authorities.

The planar-result route adds no expected numeric value and does not restate the
Geometry v2 byte oracle. Its evidence is structural: exact predecessor/final
handle ownership and generation, foreign/lookalike/deleted rejection, and
atomic incomplete/repeated/mixed-dimensional/non-handle rejection before any
Python-owned interpretation.
