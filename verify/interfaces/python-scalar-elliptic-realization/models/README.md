# Model fixture

The executable target reuses the ordinary one-dimensional constant-source
Poisson source fixture from
[`interfaces.python-native-modeling`](../../python-native-modeling/models/poisson.eqi).
The independently accepted Model contains one Cartesian interval, its two
oriented boundaries, one continuum Representation, one scalar Field, one
constant source Parameter, and three scoped Relations. No Python-specific
model or numerical semantics is introduced for this case.
