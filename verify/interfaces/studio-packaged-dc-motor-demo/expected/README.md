# Expected outcome

The native composition produces 101 aligned production samples at integer
steps `0..100`, 10 zero-order-held intervals, and 11 commits at steps
`0,10,...,100`. It presents current in amperes, angular speed in inverse
seconds, and held command in volts from one accepted interpreter trajectory.

The exact electrical, drive, and root releases reproduce the registered
resolution, Model, compilation, Run, and package/Run-binding identities. A
wrong count, time index, unit, hold interval, package node or edge, stale case
reference, foreign lineage, or superseded response prevents ready-state
publication.

No expected physical value is duplicated here. Numerical values, residuals,
controller behavior, and electromechanical power/energy acceptance remain
owned by `hybrid.packaged-dc-motor-controller`.
