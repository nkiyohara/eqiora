# Reference strategy

No new physical oracle is introduced by the Studio composition. Expected
velocity, pressure, signed flux, cylinder reaction, momentum balance, and
residual evidence remain the two independently derived and agreed routes owned
by `fluid.exact-circular-hole-stokes-2d`.

This interface case independently checks composition: the accepted exact
geometry and Model must lead to the same accepted realization plan and
observations, the authored pressure snapshot must be an output of its exact
Run, and every identity must survive the production publisher and fail-closed
Studio protocol.
