# Expected evidence

This adapter introduces no expected value or tolerance. The v1 and symmetric
v2 graph bytes, lengths, digests, observations, receipt, and lineage
membership/counts are inherited from the accepted native and Python authored
CAD cases listed in [`../references/README.md`](../references/README.md). The
511-byte planar Geometry is inherited separately and reached only through the
distinct DFG-sized graph fixture. This case freezes explicit-versus-
compatibility equality, exact native failure projection, public surface shape,
and owned-wrapper lifetime.
