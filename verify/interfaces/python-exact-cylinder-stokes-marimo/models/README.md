# Input Model

There is no new Model or fixture. The application must read
`eqiora/examples/steady-flow-past-cylinder.model.json` through
`importlib.resources.files(eqiora)` from the installed candidate, exactly as
the accepted command-line example does.

`interfaces.python-exact-cylinder-stokes-result` remains the byte, identity,
lineage, and admission authority for that one packaged Model.
