# Reference boundary

The common Plan is an application/API composition over already verified scalar
FEM/FVM consumers. Its reference is structural: typed model-unbound Cartesian
requests, exact effective Model and Mesh digests, closed policy types, complete
effective-policy projections, Plan-owned execution, and fail-closed type and
operator checks. Numerical correctness remains
owned by the existing Cartesian Poisson FEM/FVM evidence; this case derives no
scientific oracle, expected value, tolerance, or alternate formulation.
