# Cargo-only request authorities

This directory is intentionally documentation-only. The case's only
model-like inputs are the frozen Cargo-only TreeImage and exact Added-overlay
request authorities admitted by the accepted S1 contract.

They are not an Eqiora product model, physical or scientific model, numerical
model, geometry, mesh, executable input, fixture, tolerance, expected output,
or general Rust or Cargo model. This directory contains no copied manifest,
overlay carrier, record array, digest, or oracle value.

The absence of a scientific or product model neither weakens nor broadens the
accepted CargoGraph meaning of `Complete`. This README exists only to satisfy
the repository's case-directory layout and is not consumed at runtime.
