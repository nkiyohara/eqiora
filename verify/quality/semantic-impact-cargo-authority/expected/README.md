# Precommitted typed expectations

The exact Cargo authority record arrays, CargoGraph certificates, whole typed
results, fieldless terminals, and cap falsifiers remain precommitted solely in
`tools/xtask/tests/semantic_impact_cargo_authority.rs`. They are derived from
and bound to the already accepted private grammar and independent seal.

This directory contains no expected artifact consumed at runtime, and this
README is not parsed as one. It contains no copied expected record or value,
JSONL array, certificate, digest, count, terminal table, cap number, tolerance,
snapshot, golden file, fixture, or generated output.

This leaf creates no second expected-value registry and neither changes nor
supplements the evidence test's authority. Its only purpose is to satisfy the
repository's case-directory layout.
