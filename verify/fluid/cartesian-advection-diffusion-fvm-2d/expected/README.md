# Expected evidence policy

The registered integration test is the executable numerical oracle. It drives
the ordinary canonical compile, typed Realization, conservative assembly,
reference solve, and evidence-measurement path. No hand-entered or fixture-
local solver output is admitted.

The executable test remains the oracle for exact face-packet counts, assembly
receipt closure, complete finalized-CSR/right-hand-side reconstruction,
accepted-solution physical residual replay, interior equal-and-opposite
scatter, per-step and accumulated balance, extrema, reflection, identity drift,
boundary-law rejection, and solver lineage. A non-unit
coordinate/state/weak-functional scale substitution must also reconstruct the
same physical state; otherwise the integration test fails. The exact minmod
Realization additionally owns greater-than-1.6 observed spatial order for its
nominally second-order reconstruction, limiter activation,
face-hull bounds, Courant admission, constant preservation, and explicit
unsupported-scheme rejection. A future generated
convergence table may summarize mesh size, time step, L2 error, observed order,
and balance defect, but must not replace those assertions.
