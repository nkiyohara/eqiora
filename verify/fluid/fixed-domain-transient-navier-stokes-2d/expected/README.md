# Acceptance contract

The direct source must lower to one package-neutral fixed-domain conservative
Navier--Stokes model. The coherent-SI reference bridge must bind the exact
model, explicit Realization revision, and authenticated mesh envelope to
MINI/P1, degree-eight positive quadrature, backward Euler, energy-skew
convection, analytic Newton JVP, and serial host BiCGSTAB through the private
discrete block system. Every Newton CSR must be bound back to that block
identity, and the accepted trajectory must retain the complete resolved
Realization, exact executing solver-adapter identity, and a nonzero
validated-materialization count. Solver-adapter substitution after preparation
must be unrepresentable at the public run operation.

Two nontrivial steps must pass directly assembled nonlinear and momentum residual,
incompressibility, zero-pressure-integral, convective-action, and zero
convective-self-work checks. The conservative-to-skew defect identity must be
reproduced after global assembly. Every analytic Jacobian column is checked
against the independent residual. Fixed-mesh step doubling in the MINI mass
norm must show first-order temporal convergence, while a tenfold tighter
nonlinear solve changes the finest final state by less than one thousandth of
the finest time difference in the same norm. Inconsistent essential or
interior velocity, pressure mean, gauge, stale mesh, pressure-policy drift,
solver-adapter drift, under-integration, nonlinear failure, unrepresentable time, wrong
outer-product operands, density drift, incomplete boundary closure, and hidden
ALE velocity must fail before accepted trajectory evidence is returned.
