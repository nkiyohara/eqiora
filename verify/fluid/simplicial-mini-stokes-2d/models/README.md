velocity are Rust numerical callbacks in
`crates/eqiora/tests/simplicial_mini_stokes_2d.rs`.

fixture validates the mixed numerical Realization needed before canonical
fluid meaning is admitted. It does not claim canonical Stokes Relations,
source lowering, a fluid ModelPackage, package resolution, or Model artifact
