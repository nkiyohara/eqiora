# Reference provenance

The transverse analytic oracle is the same independently evaluated
one-dimensional advection--diffusion inflow step used by the nonperiodic
Cartesian transport case, with its physical coordinate mapped to y. The seam
oracle is derived directly from the admitted TPFA transmissibility and oriented
first-order upwind flux on a four-by-four unit box; it does not call the seam
pairing implementation.
