# Reference provenance

The exact solution and forcing are derived directly in
[`models/problem.md`](../models/problem.md); no external numerical table or
third-party dataset is used.

`expected/convergence.csv` is generated by the repository example after
compiling [`models/poisson.eqi`](../models/poisson.eqi); only the exact field
used to measure error comes from this analytic definition. The table is
retained separately so CI can detect unintended semantic or numerical changes.
Its values are evidence, not an independent reference solution.
