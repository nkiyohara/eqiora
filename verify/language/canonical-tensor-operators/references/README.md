# References

The semantic oracle is
[`RFC 0038`](../../../../rfcs/0038-canonical-tensor-structure-operators.md):
the operators have closed mathematical component rules and derive their exact
extent and support from the typed operand rather than a realization sidecar.

The artifact oracle is exact canonical-byte, domain-separated-digest, and typed
replay equality under explicitly selected Model and Transaction wire v4.
Legacy closure is a negative oracle: neither a v3 encoder nor a payload with a
forged v3 schema tag may accept a v4-only expression.

The elasticity-shaped source is not a numerical reference solution. A future
solid verification case must independently specify boundary conditions,
realization, quantities of interest, and falsifying error or consistency
evidence.
