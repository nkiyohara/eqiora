# Typed fixture

The evidence target constructs the smallest typed residual DAGs directly:

- a square Cartesian tensor with `symmetric_part` and a Volume scalar with
  `isotropic_lift`;
- an exact rational pair of equivalent component definitions;
- one shaped residual containing two distinct Parameter identities, lowered
  through typed local scalar input slots; and
- one scalar value restricted from an exact parent Volume to its Boundary.

No new source syntax is claimed. In particular, the reserved package
`PureOperator` declaration tag is not a parser, compiler, or package-authoring
feature in this slice. Existing Model and Transaction wire v1--v4 remain
unchanged.
