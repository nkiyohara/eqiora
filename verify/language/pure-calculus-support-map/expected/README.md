# Acceptance

The registered target must prove:

- stable content identity for a bounded capture-free typed definition;
- typed expansion of the accepted symmetric-part and isotropic-lift tensor
  operators;
- independent replay of exact rational normal-form proofs for two equivalent
  component expressions, while cross-wired source/proof replay and a different
  physical type context fail;
- component scalarization retains two distinct Parameter identities through
  dense typed local input slots, rather than merging equal-valued coordinates
  or fabricating placeholder Semantic Parameters; and
- a typed trace support map accepts only the exact parent Volume and owning
  Boundary, with explicit orientation and pointwise pairing.

This target must not claim source-level user operator definitions, float
reassociation, arbitrary symbolic equivalence, numerical transfer, a new
Kernel expression kind, or any new Model/Transaction wire version. The
separate `language.canonical-pure-operator` target owns the bounded source,
generic-application, and v5 extension without widening this case.
