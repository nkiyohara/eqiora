# Pure calculus and support map

This case verifies the first proof-carrying mathematical composition seam
above immutable Kernel expression meaning. A fully typed residual is the only
entry. The L2 calculus expands the existing `symmetric_part` and
`isotropic_lift` operators through capture-free formal slots, exact result
axes, rational literals, Kronecker delta, and bounded algebra. Definitions are
content-addressed independently of source or package names.

Two differently ordered exact expressions, `2 * (A + A^T) / 2` and
`A + A^T`, produce distinct definition identities and independently replayed
proofs of one admitted exact normal form. This proof is for semantic
classification only. It never authorizes reassociation of the ordered
floating-point program used by a numerical backend.

The same test proves that component scalarization retains two distinct
Parameter identities through typed IR-local input slots. Each slot has a dense
ordinal and the exact scalar symbol coordinate; it is not a fabricated
Semantic Parameter and has no durable wire form. The first support map is only
an exact parent Volume to owning Boundary trace restriction. The map carries
semantic source, target, orientation, pairing, and intent; it has no mesh
entity, discrete space, interpolation coefficient, mortar rule, or quotient
matrix.
