# Acceptance

The registered integration target must prove all of the following:

- N-ary and chained fragments compile to equal Model identities and graph
  transactions;
- their admitted current Model canonical bytes and semantic digests are
  identical;
- both forms emit exactly one three-member canonical Connection;
- the hierarchy-free N-ary and chained fixtures each emit one exact
  three-member Connection through the direct flat lowering path;
- the chained form preserves both explicit fragment origins without changing
  canonical identity;
- the Wrapper exposure is absent from ordinary entity lookup and from Kernel
  Port nodes, and is not misrepresented as a Connection alias;
- that Connection retains the internal Leaf and external Leaf Ports and has
  both contributing source origins; and
- missing membership, double ownership, and a set with no retained owner fail
  before any compiled transaction is returned.
