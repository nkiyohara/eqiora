# Acceptance criteria

- Current Models spanning spatial, scalar-physical, and field-boundary meaning
  each produce a sealed reference containing their exact digest, typed Model
  identity, and semantic revision.
- Every reference constructs the unchanged Realization v1 wire and a coherent
  Run v2 content-link chain.
- Current-only replay preserves the exact reference accepted by the
  Realization.
- Direct current artifact-owner replay reconstructs the immutable Kernel
  Program without changing the typed reference.
- No historical wire decode, auto-detection, schema upgrade, execution,
  numerical acceptance, or physical-result claim follows from the identity
  chain.
