# Reference generation

`generate_fixture.py` uses the official VTK Python 9.5.2
`vtkXMLUnstructuredGridWriter` in uncompressed ASCII mode. Point insertion,
cell insertion, and DataArray insertion are deliberately explicit and stable.
The two triangle connectivities are counter-clockwise in the XY plane.

The independently authored expected table is not generated by this script.
After regeneration, inspect the XML and compare decoded content with
`../expected/summary.json` before accepting a source-digest change.
