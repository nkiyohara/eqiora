# Acceptance

The N-ary and partitioned roots have different source-bundle digests and
exact resolution records, but one package semantic identity, canonical Model
v2, and Model digest. Both lower to the same `10 x 10` scalar physical affine
problem—including ordered semantic DAGs, parameter bindings, CSR—and the same
analytic 12 V, 2 ohm solution. Only the root source entry may differ between
the two package-compilation records.

The two forwarding Ports of `ResistiveBranch` are not Kernel unknowns or
entity aliases. The retained internal resistor terminals participate in two
maximal Connections. The N-ary low net keeps two source origins; the
partitioned low net keeps three, without allowing provenance spelling to
enter semantic identity. The retained Connection full identity must be
reconstructible from the exact root package namespace, root Model occurrence,
reserved root net declaration path, and retained member identities. Dependency
definition, root instance, parameter binding, and root fragment spans must
remain complete origin tuples.

An imported branch whose public boundary is not closed may remain a
definition-valid package release, but selecting it as the root Model must
fail during locked compilation before a Model or graph mutation is exposed.
