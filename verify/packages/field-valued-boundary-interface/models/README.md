# Models

`components.eqi` defines one generic, mesh-independent two-dimensional
boundary carrier. `coupled.eqi` and `coupled-permuted.eqi` spell the same
coincident maximal interface in different declaration, binding, endpoint, and
dependency-alias orders. The negative sources separate geometric coincidence
from exact parent binding.

No model contains a mesh, facet, quadrature rule, transfer map, solver, or
manual orientation sign.
