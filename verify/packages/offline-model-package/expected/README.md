# Archived evidence

`historical-alpha1-compilation.json` is an immutable archival release artifact.
It is not a current expected value, compatibility view, decoder requirement, or
input to the current package execution path.

Current package resolution, source admission, store integrity, provenance, and
analytic circuit behavior are checked as claim-local relations in the product
test. Their incidental Model, Compilation, Run, binding, and package digests
are not evidence.
