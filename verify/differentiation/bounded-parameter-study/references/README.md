# Composition reference

The reference calls the existing accepted differentiable program separately at every complete
requested point before invoking the map. It compares exact program/input identity, point bits,
Field coefficient bits, accepted system/output fingerprints and exposed solve evidence.

Q1 and TPFA each execute `[p2,p1,p2]` and its explicit permutation. Numerical equality never
removes a requested occurrence. Prior JVP/VJP actions independently establish the retained-member
isolation expectation before later evaluations occur.

The [private companion](../../bounded-parameter-study-private/README.md) rejects membership
and evaluator substitutions through the same production-private admission. These are composition
falsifiers, not independent scientific solutions. No expected value or tolerance is derived
from the map implementation.
