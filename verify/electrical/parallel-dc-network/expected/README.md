# Acceptance

The registered source and client-neutral native declarations must each close
to one complete scalar physical Semantic Model and satisfy all of the
following:

- reversing definition and connection insertion while retaining the same
  typed IDs leaves canonical current Model bytes, digest, and composed junction
  residuals unchanged;
- current Model bytes round-trip to the exact original bytes and digest;
- the public native facade uses the current owner and matches source-authored
  values by semantic Port name despite independently minted graph IDs;
- structural affine admission produces one square 14-by-14 general CSR system
  in canonical unknown and residual order;
- source and fresh-ID native systems both submit the exact analytic vector to
  faer BiCGSTAB with identity preconditioning and `Fast` reduction, then
  accept it as an initial-residual witness through the same CSR and
  original-DAG gates with semantic residual no larger than `1.2e-11`;
- voltages and signed currents agree with the analytic solution within
  `2e-11`, and both conserving junction sums vanish within the same bound;
- the original relation and generated junction DAGs independently reaccept
  the returned values;
- adding an unrelated ordinary Relation changes whole-model identity but
  leaves the selected physical closure and CSR executor input unchanged;
- Conjugate Gradient rejects the general operator before execution without
  silently substituting an algorithm.
