# Eqiora.Electrical.Circuits

Reusable, composed scalar electrical circuits built from the exact
`Eqiora.Electrical.Basic` package. The initial release exports one closed
parallel-DC component whose public interface consists only of typed scalar
parameters.

This package is verification-sized. It does not yet expose physical boundary
ports, cross-package connection-set union, replaceable components, nonlinear
devices, transient behavior, or production circuit coverage.
