# Release notes

Eqiora `0.1.0a1` is the first public alpha. It establishes a coherent public
identity and a bounded compatibility policy; it is not a stable-1.0 promise.

## 0.1.0a1

The repository
[changelog](https://github.com/nkiyohara/eqiora/blob/main/CHANGELOG.md) is the
single maintained record of notable changes. It distinguishes additions,
changes, and compatibility-relevant removals.

Python packaging and candidate validation follow the
[Python release policy](https://github.com/nkiyohara/eqiora/blob/main/docs/development/python-release-policy.md).
The [release notes](https://github.com/nkiyohara/eqiora/releases/tag/v0.1.0a1)
bind the exact source, artifact manifest, support matrix, and limitations.

For exact support at any revision, use the
[capability matrix](capabilities.md) and case-level
[evidence catalog](evidence/index.md).
