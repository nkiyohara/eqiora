Its `Pin` is a scalar-physical connector: across is voltage in V, through is
current into the component in A. The declaration spells dimensions in
[SI base units](/reference/language/units/).

| Declaration | Required parameter | Ports and mathematical contract |
|---|---|---|
| `IdealVoltageSource` | `voltage`, V | `positive`, `negative`: fixes their voltage difference and conserves current |
| `Resistor` | `resistance`, ohm | `positive`, `negative`: voltage difference equals resistance times positive-port current; conserves current |
| `Ground` | None | `terminal`: fixes its across voltage to zero, without prescribing its current |

These are ideal, time-independent declarations. Ground fixes potential, not current.

## Grounded voltage divider

<Code code={circuit} lang="eqiora" title="electrical.eqi" />

The supply fixes 12 V across two series resistors, 1 kΩ and 2 kΩ.
Ohm's law and current conservation give `12 / (1000 + 2000) = 0.004 A`;
the midpoint is `0.004 * 2000 = 8 V` relative to ground.
The session observes the named Ports through their across (voltage) and through
(current into the component) roles. Observation adds no equation.

After [installing Eqiora](/get-started/#install-with-uv), save the source above
as `electrical.eqi` and run:

```python
from pathlib import Path
import eqiora

project = Path("divider")
(project / "src").mkdir(parents=True, exist_ok=True)
(project / "src/main.eqi").write_text(Path("electrical.eqi").read_text())
(project / "eqiora.toml").write_text(
    '[package]\nname = "org.example.Divider"\nversion = "0.1.0"\nentry = "main"\n'
)
store = Path("package-store")
store.mkdir(exist_ok=True)
resolution = eqiora.add_bundled_dependency(
    project, store, "Eqiora.Electrical.Basic", version="0.1.0"
)
model = eqiora.compile_package(store, resolution, entry="VoltageDivider")
session = model.execution_session(end_time_s=1, max_step_s=1, inputs={})
print(session.through("upper.positive"))   # approximately 0.004 A
print(session.across("lower.positive"))  # approximately 8 V

# Keep the exact closure for offline reopening.
vendor = project / "vendor"
vendor.mkdir(exist_ok=True)
eqiora.vendor_project(project, store, vendor)
resolution = eqiora.open_project(project, vendor)
model = eqiora.compile_package(vendor, resolution, entry="VoltageDivider")
```

The distribution supplies the exact library source. The ordinary package lock
contains the caller and `Eqiora.Electrical.Basic@0.1.0`; this operation requires
no network fetch or provider installation. The reference execution session solves
the algebraic circuit at initialization. Its horizon is an execution setting,
not a resistance, voltage, or Model parameter.

The final lines vendor the closure for offline use. After moving the project,
open it from that vendored store and compile through the same API.

The installed-package product test checks the analytic values, Model byte replay,
and vendored reopening after deleting the original store. Removing the entire
ground rejects execution. This is one bounded real-scalar, time-independent
reference circuit; it makes no general nonlinear circuit solver claim.
