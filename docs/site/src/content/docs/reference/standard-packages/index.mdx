Browse the `.eqi` declarations distributed in the **Eqiora 0.1.0a7 source
archive** by physical purpose:

| Purpose | Lookup |
|---|---|
| Impose a DC voltage, resistance or electrical reference potential | [Electrical components](/reference/standard-packages/electrical/) |
| Express a small-strain elastic balance, clamp a boundary or leave it traction-free | [Continuum laws and boundaries](/reference/standard-packages/continuum/#elastic-balance-and-boundaries) |
| Bind density, viscosity, velocity and pressure to an inertial Stokes law | [Inertial flow law](/reference/standard-packages/continuum/#inertial-flow-law) |

Each worked example shows bindings, units and the canonical declaration, and is
compile-checked with a7. For executed problems, see the [gallery](/gallery/).

## Source and installation boundary

The [PyPI release](https://pypi.org/project/eqiora/0.1.0a7/#files) publishes a source
archive alongside Python wheels. Download and extract `eqiora-0.1.0a7.tar.gz` to
inspect its `packages/` directory. The Python wheel does not itself contain these
eight standard-package source files. `uv add eqiora==0.1.0a7` installs the Python
runtime; it does not install their semantic dependency closure.

The worked examples compile unchanged released declarations locally. Sources with
qualified names such as `mechanics.VelocityTractionBoundary` instead require their
exact package alias and closure. a7 can compile a prepared package closure; the
newer bundled-catalog, `open_project` and Git-fetch authoring APIs are not in this release.
