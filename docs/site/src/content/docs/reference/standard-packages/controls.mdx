<ExactSourceLink kind="blob" path="packages/Eqiora.Controls.Sampled/src/sampled.eqi">Eqiora.Controls.Sampled</ExactSourceLink>
contains ordinary real-scalar components.
Every occurrence borrows the caller's exact clock and owns one initialized memory.

| Component | Inputs | Outputs at the tick |
|---|---|---|
| `UnitDelay` | `u: 1` | `y = pre(memory)`; commits `next(memory) = u` |
| `DiscreteIntegrator` | `rate: 1/s` | `before = pre(memory)` and `after = next(memory)`; commits `pre(memory) + period(tick) * rate` |

Both require `clock tick: periodic` and `parameter initial_value: 1`. There is
no default period or default initial value. The integrator's named endpoints let
you explicitly choose the old or updated value without adding another state.
All tick equations are simultaneous, regardless of their written order.

For initial memory 3 and rates `[2, -1, 3] /s`, quarter-second ticks publish
`before = [3, 3.5, 3.25]` and `after = [3.5, 3.25, 4]`. Half-second ticks instead
publish `[3, 4, 3.5]` and `[4, 3.5, 5]`. A delay initialized to 5 publishes
`[5, 2, -1]` for either period. These sequences include the first tick at zero;
no output sample exists before that tick.

## Physical units through explicit adapters

The current blocks specialize real, dimensionless scalar memory.
For a physical quantity, divide its signal and rate by a fixed nonzero scale
with that quantity's dimension, normalize initial memory with the same scale,
and multiply the selected output by the scale. The compiler checks these
ordinary equations; there is no implicit unit cast.

The executable
<ExactSourceLink kind="tree" path="examples/standard-sampled-components">voltage and displacement example</ExactSourceLink>
uses 2 V and 0.5 m scales with distinct input sequences. Its local adapters contain no memory. It demonstrates
both periods, typed V/s and m/s rates, and the installed Python
`add_bundled_dependency` → `compile_package` → `execution_session` path. The exact
dependency closure contains only the caller and `Eqiora.Controls.Sampled@0.1.0`.
The example README supplies the complete commands after installation with uv.

The clock is owned by the caller Model and supplied to each block occurrence.
Equal periods do not make distinct clock identities interchangeable. Supply
sampled inputs on the same clock; these blocks do not convert continuous or
foreign-clock signals implicitly.
