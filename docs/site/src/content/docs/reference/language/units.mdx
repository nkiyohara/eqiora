[Language overview](/reference/language/) · Installed release: **0.1.0a7**

Write a physical dimension after `:`. Products, quotients and integer powers of SI
base symbols describe dimensions; numerical declaration values use the corresponding
coherent SI units. The symbols are `kg`, `m`, `s`, `A`, `K`, `mol` and `cd`; `1` is
dimensionless. A `dimension` alias abbreviates a dimension, not a value conversion.

<Code code={source} lang="eqiora" title="units.eqi" />

Here `210e9` is 210,000,000,000 Pa, or 210 GPa. The alias `Pressure` does not rescale
the number. To enter 10 ms in a scalar time parameter, use `parameter duration: s = 0.01;`.
Do the input conversion explicitly; do not change the equations to compensate for
a wrongly scaled parameter.

| Physical quantity | Dimension spelling used by this release |
|---|---|
| Pressure or stress, Pa | `kg / (m * s ^ 2)` |
| Voltage, V | `kg * m ^ 2 / (s ^ 3 * A)` |
| Resistance, ohm | `kg * m ^ 2 / (s ^ 3 * A ^ 2)` |
| Dynamic viscosity, Pa·s | `kg / (m * s)` |

The [released standard declarations](/reference/standard-packages/) use these dimensions.
Case matters: `A` is electric current and `s`
is time. Addition and subtraction require matching dimensions. The
[declaration example](/reference/language/declarations/) keeps voltage and
resistance distinct even though both are scalar numbers.

<Aside type="caution" title="No bracketed input quantities in a7">
  `210 [GPa]` and `10 [ms]` are not accepted a7 inputs. Convert to coherent SI
  values before passing numbers to the Model.
</Aside>

Periodic clocks use their separate exact rational-time spelling; see
[Equations and state](/reference/language/equations/#periodic-state).
