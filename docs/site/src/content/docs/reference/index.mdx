Look up a declaration, find a physical building block, or inspect an API signature.
The language and standard-source pages name the installed release they exercise.
The generated API and protocol pages describe their labelled documentation commit;
they may include features newer than that release.

<Aside type="note" title="Choose a reference">
  Start with [Get started](/get-started/) for installation and a first run.
  [Learn](/textbooks/) explains the physics; Reference explains the syntax and
  supplied declarations. [Capabilities](/capabilities/) records execution limits.
</Aside>

Python and Rust are library references. CLI, control-v2 and MCP are separate
interfaces, not additional SDKs. Check each page's source identity before using a
new API with an older installation.
