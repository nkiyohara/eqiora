## 0.1.0a7 — equation authoring and reusable numerical setup

[Eqiora 0.1.0a7](https://github.com/nkiyohara/eqiora/releases/tag/v0.1.0a7)
adds natural equation authoring to Python `Source` and infers dimensions for
model-local aliases. Scalar conservation handling extends across Cartesian
1D–3D models, and elasticity calculations share continuum and material operations.
Runs prepare reusable execution data and Faer factorizations once, and
cancellation makes the last accepted State available.

Mesh generation uses `MeshPlan`. Physics-specific dimension aliases and the
Marimo/Jupyter example paths were removed; use derived dimensions and the
maintained Colab examples when migrating.

## 0.1.0a6 — scalar properties and local file interchange

[Eqiora 0.1.0a6](https://github.com/nkiyohara/eqiora/releases/tag/v0.1.0a6)
adds scalar property bindings, affine coefficients, authored scalar primal
Formulations, and directional Stokes correspondence. Language additions include
`math.pi`, typed model-local `let`, and derived-dimension aliases. Equivalent
additive equation orientations produce the same residual.

Plans, Results, and Trajectories gain atomic local file I/O. Rust adds a common
transient `RunRequest`. The cylinder examples use finer presentation meshes
and clearer startup animations, and clean Colab Gmsh startup was fixed.

## 0.1.0a5 — inspect formulations and save execution artifacts

[Eqiora 0.1.0a5](https://github.com/nkiyohara/eqiora/releases/tag/v0.1.0a5)
lets users inspect the effective Formulation selected for a Plan and save
resolved Plans, restartable States, Trajectories, and Results. Loading checks
that the supplied upstream objects match the saved artifact.

Static scalar, elasticity, and Stokes runs return the common Result. The optional
`eqiora.View` viewer displays 2D Geometry, Mesh, selections, and scalar Fields
from Python. Package compilation now binds a public Component to supplied
Geometry and Parameters; older v1 compilation records are no longer decoded.

## 0.1.0a4 — common run workflow and cylinder startup

[Eqiora 0.1.0a4](https://github.com/nkiyohara/eqiora/releases/tag/v0.1.0a4)
uses `.eqi → eqiora.compile() → eqiora.resolve() → eqiora.run()` with Geometry,
Mesh, and numerical settings supplied by the application. It adds a Colab
walkthrough of the first steps of transient flow around a cylinder. The
packaged DC-drive example also runs in Studio.

## 0.1.0a3 — Gmsh meshing

[Eqiora 0.1.0a3](https://github.com/nkiyohara/eqiora/releases/tag/v0.1.0a3)
uses Gmsh 4.15.2 for the exact-cylinder Python workflow and updates its pressure
output and Gallery image.

## 0.1.0a2 — second public alpha

[Eqiora 0.1.0a2](https://github.com/nkiyohara/eqiora/releases/tag/v0.1.0a2)
expands the published Python, CLI, MCP, and Gallery interfaces. See the
[capabilities](/capabilities/) for the available problem classes and environments.

## 0.1.0a1 — first public alpha

[Eqiora 0.1.0a1](https://github.com/nkiyohara/eqiora/releases/tag/v0.1.0a1)
publishes the first Python package and its installation instructions. Each
linked release retains its original downloads and detailed release notes.
