Textbooks will teach mathematics, physics, and numerical methods with Eqiora.
They complement [Docs](/get-started/), which explains product use;
[Gallery](/gallery/), which presents complete simulations; and
[Reference](/reference/), which records exact interfaces.

<Aside type="note" title="Editorial status">
  This index publishes the intended learning map, not finished books. Every
  series below is **Planned**, has **0 executable chapters**, and targets the
  current <ReleaseIdentity /> surface. A chapter becomes available only when
  its derivation, runnable source, comparison boundary, accessibility, and
  explicit non-claims ship together.
</Aside>

## Chapter navigation contract

When chapters ship, derivation and learning progression stay here. A completed
simulation links to Gallery, usage explanation to Docs, exact signatures to
Reference, supported boundaries to Capabilities, and manifest or oracle detail
to the technical evidence catalog. This keeps each authority in one place.
