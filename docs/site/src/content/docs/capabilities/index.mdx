This page answers **what can Eqiora do today, and how was that conclusion reached?**
It is organized by problem family. The
repository <ExactSourceLink path="docs/capability-matrix.md" kind="blob">capability
matrix</ExactSourceLink> remains the maintained complete product map.

## Status vocabulary

These labels describe different facts; they are not a single maturity ladder.

- **Available** — a user-visible contract or surface exists.
- **Executable** — at least one described path runs end to end.
- **Checked** — focused product tests exercise the stated behavior.
- **Verified** — reproducible registered evidence supports the stated result.

<Aside type="caution" title="Read the boundary, not only the label">
  Every summary names the exact current path. Eqiora remains alpha software.
</Aside>
