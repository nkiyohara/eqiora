Run a small model, then change it and see the difference. You need two files and
a Python environment—not a repository checkout, mesh generator or editor extension.

## Install with uv

This example uses the published **Eqiora 0.1.0a7** release on **Linux x86-64**
with ordinary-GIL **CPython 3.13**. Its manylinux wheel requires glibc 2.17 or
newer. macOS, Windows and free-threaded Python are not supported by this release.

Install [uv](https://docs.astral.sh/uv/getting-started/installation/) if you do
not have it, then open a terminal in a new working folder:

```bash
mkdir first-eqiora-model
cd first-eqiora-model
uv venv --python 3.13
uv pip install --python .venv/bin/python 'eqiora==0.1.0a7'
```

Keep the following files in this folder, beside `.venv`. No shell activation is
needed: each run below explicitly selects that environment.

## Predict the result

Let a dimensionless quantity $x$ start at 1 and decay at rate
$k=1\,\mathrm{s}^{-1}$:

$$
\frac{\mathrm{d}x}{\mathrm{d}t}+kx=0,\qquad x(0)=1.
$$

The solution is $x(t)=\exp(-kt)$. After one second, predict
$x(1)=\exp(-1)\approx0.367879$—about 37% of the initial value.

## Run and inspect

```bash
uv run --no-project --python .venv/bin/python python run.py
```

You should see values close to:

```text
t=0.25, x=0.7788007829
t=0.50, x=0.6065306597
t=1.00, x=0.3678794412
```

The last line agrees with the hand prediction. The result is printed in the
terminal; this small script does not create a plot or save a result file.

## Change the model

In `decay.eqi`, change just the rate declaration to:

```eqiora
parameter rate: 1 / s = 2;
```

Before rerunning, predict $x(1)=\exp(-2)\approx0.135335$: doubling the rate makes
the quantity decay faster. Run the **same command and script** again. Its last
line should now be close to `t=1.00, x=0.1353352833`.

You changed the model, not the time method. Restore `rate` to 1 when following
the [ODE lesson](/textbooks/mathematical-modeling/ordinary-differential-equations/).

## If something goes wrong

- **`uv: command not found`:** install uv using its linked instructions, reopen
  the terminal and check `uv --version`.
- **No compatible distribution:** check the Linux x86-64/glibc requirements
  above. Use CPython 3.13, not a free-threaded build.
- **Wrong Python or missing `eqiora`:** run
  `uv run --no-project --python .venv/bin/python python -c "import eqiora; print(eqiora.__version__)"`.
  It should print `0.1.0a7`. Use the same folder and environment for installation
  and execution; do not substitute an unrelated system Python.
- **Model file not found:** keep `decay.eqi` beside `run.py` and run from their
  folder, or pass its path: `python run.py path/to/decay.eqi` inside the selected
  environment.
- **A source diagnostic:** misspelling `rate` as `missing_rate` in the relation
  produces `EQ0603: unresolved expression symbol` in this release. Correct the
  name to match the declaration. Changing the rate's unit to `m` instead produces
  an addition/subtraction dimension mismatch: the two terms must both have
  inverse-time units.
