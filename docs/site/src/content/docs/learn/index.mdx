Learn how a physical assumption becomes an equation, what that equation predicts,
and how to recognize when a model is missing something. Each lesson includes
worked reasoning and exercises; you can read it without installing Eqiora.

## Start a learning path

[Mathematical modeling](/learn/mathematical-modeling/) connects eight lessons,
from assumptions and units to evolving state, conservation and boundaries.
Start with [Models are not simulations](/learn/mathematical-modeling/models-not-simulations/),
or go straight to the [decay experiment](/learn/mathematical-modeling/ordinary-differential-equations/)
after [Get started](/get-started/).

## Connect the ideas to a result

Follow the [steady cylinder-flow investigation](/gallery/exact-cylinder-steady-stokes/)
or [mixed-boundary elasticity](/gallery/mixed-boundary-elasticity/) to see
assumptions, numerical choices and a plotted result together.
[Guides](/guides/) explain the practical steps; [Reference](/reference/) defines
the constructs and signatures.
